
# 📊 Excel Senior Challenge — Transforming Basic Data into Enterprise Solutions

> **Portfolio Project / Practical Study**
> **Technologies:** Microsoft Excel (Advanced Formulas, Conditional Formatting, Data Validation)

---

## 📌 About the Project

**I am currently studying and applying** how to transform basic operational routines into enterprise-grade analytical tools.

This repository documents the evolution of 3 basic Excel exercises into a complete, integrated solution designed to support decision-making, budget control, and data governance.

---

## 🎯 Structure of the 3 Modules

### 1. 🔹 Financial Control (Budget vs. Actual)

* **Objective:** Budget tracking and variance analysis by department and category.
* **Features:** `SUMIFS` (`SOMASES`), `IFERROR` (`SEERRO`), automated KPIs, and percentage variance calculations.
* **Impact:** Clear visibility into budget overruns and support for executive financial decision-making.

### 2. 🔹 SLA & Deadline Monitoring

* **Objective:** Visual management of operational deadlines and identification of bottlenecks.
* **Features:** Formula-based Conditional Formatting (`TODAY()` / `HOJE()`, multi-criteria rules) and status alert scales (Critical, Warning, Normal).
* **Impact:** Immediate detection of pending tasks and visual prioritization of workflows.

### 3. 🔹 Data Governance & Standardization

* **Objective:** Data Quality enforcement directly at the input stage.
* **Features:** Dynamic dependent drop-down lists (`INDIRECT` / `INDIRETO`), date range validation, and duplicate prevention rules.
* **Impact:** Elimination of typos and consistent formatting required for reliable downstream analysis.

---

## ⚙️ Advanced Techniques & Formulas Used

* **Logic & Conditions:** `IF`, `IFS`, `AND`, `OR` (`SE`, `SES`, `E`, `OU`)
* **Aggregations:** `SUMIFS`, `COUNTIFS`, `SUBTOTAL` (`SOMASES`, `CONT.SES`, `SUBTOTAL`)
* **Lookup & Filter:** `XLOOKUP` / `VLOOKUP`, `INDEX` + `MATCH`, `FILTER` (`PROCX` / `PROCV`, `ÍNDICE` + `CORRESP`, `FILTRO`)
* **Data Integrity:** Dynamic data validation rules and input error handling
